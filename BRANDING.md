# Captain Notes

Identité : carnet droit à coin replié et deux lignes, blanc sur vert de référence RGB(67,150,130),
`#439682`. Signature HTML en minuscules sur deux lignes : « captain / notes ».

Fichiers actifs dans `priv/static/images/brand/` :
- `captain-notes-notebook.png` : original ;
- `captain-notes-notebook-192.png` et `captain-notes-notebook-512.png` : icônes de lancement ;
- `captain-notes-notebook-180.png` : icône Apple ;
- `captain-notes-notebook-32.png` : favicon.

Le symbole est intégré à la connexion. Le manifeste définit le nom Captain Notes.
Aucun cache hors ligne des données scolaires n'est ajouté.
Les fichiers de la première proposition Pronotex sont conservés mais ne sont plus référencés.

Conception : outil intégré ImageGen. Redimensionnements techniques avec sips.
